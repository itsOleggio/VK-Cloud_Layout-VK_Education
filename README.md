# VK Cloud — вёрстка лендинга

Учебная вёрстка промо-страницы облачной платформы VK Cloud, выполненная в рамках домашнего задания VK Education. Страница написана на чистых HTML и CSS, без JavaScript и сборщиков.

**[Открыть демо на GitHub Pages](https://itsoleggio.github.io/VK-Cloud_Layout-VK_Education/)**

## Что есть на странице

- **Шапка** — логотип, кнопки входа и регистрации, главный оффер.
- **Миграция** — условия акции и кнопки для заявки.
- **Продукты** — карточки виртуальных серверов, виртуальных сетей и объектного хранилища.
- **Надёжность** — сетка преимуществ с карточками, которые переворачиваются при наведении.
- **Бегущая строка** — бесконечная анимация с показателями платформы.
- **Подвал** — навигация, социальные сети и контактная информация.

## Технологии и приёмы

- Семантическая разметка HTML5: `header`, `main`, `section`, `footer`.
- Адаптивность через медиазапросы: отдельные стили для экранов до 376 px и от 377 px.
- 3D-переворот карточек на CSS: `perspective`, `transform-style: preserve-3d`, `backface-visibility`.
- Бегущая строка на `@keyframes`.
- Шрифты Inter и Ubuntu из Google Fonts.

## Запуск локально

Сборка и установка зависимостей не нужны. Достаточно запустить любой статический сервер из корня проекта:

```bash
git clone https://github.com/itsOleggio/VK-Cloud_Layout-VK_Education.git
cd VK-Cloud_Layout-VK_Education
python3 -m http.server 8000
```

После этого откройте в браузере <http://localhost:8000>.
